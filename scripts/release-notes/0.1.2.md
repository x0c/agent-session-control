# 0.1.2

Built-in Google Antigravity (`agy`) runtime support, composer boundaries, and `sesskit>=0.3.2` native-history alignment.

## Changes

- **Built-in `antigravity` runtime (`agy`)**: Added `"antigravity"` to `BUILTIN_RUNTIME_IDS`, `default_registry()`, `_resume_argv()` (`agy --dangerously-skip-permissions --conversation <id>`), and `between_rules` composer parsing validated against live `agy 1.5.8` TUI panes.
- **Untrusted workspace prompt detection**: Expanded `_BLOCKING_DIALOG_RE` to recognize Antigravity's `↑/↓ Navigate · enter Confirm` dialog footer without dropping focus into trust prompts.
- **MCP boundary**: Live `agy 1.5.8` rejects `mcpServers` in `--settings` (`unknown setting "mcpServers"`), so per-session MCP channel injection is explicitly declared unsupported (`MCP_CHANNEL_UNSUPPORTED`) and `agent-session-control acp --runtime antigravity` refuses at the stdio MCP baseline gate (while documenting native `agy acp`).
- **SessKit alignment**: Upgraded the `history` extra pin to `sesskit>=0.3.2` (`sesskit-0.3.2-py3-none-any.whl`) to use Antigravity's typed activity snapshots (`typed_activity=True`, `incremental_reading=True`, `structured_questions=True`).
- **End-to-end & live disposable verification**: Added unit, end-to-end controller (`plan`, `create`, `start_turn`, native `HistoryObserver` correlation, `load_history`, `resume`), ACP refusal, and live disposable `tmux` + `agy` composer tests, and updated docs and the bundled `agent-session-control` skill.

## Install

```bash
uv venv
source .venv/bin/activate
VERSION=0.1.2
BASE=https://github.com/x0c/agent-session-control/releases/download/v${VERSION}
SESSKIT=https://github.com/x0c/sesskit/releases/download/v0.3.2/sesskit-0.3.2-py3-none-any.whl

python -m pip install "${BASE}/agent_session_control-${VERSION}-py3-none-any.whl"
# With native-history observation:
python -m pip install "${SESSKIT}" "${BASE}/agent_session_control-${VERSION}-py3-none-any.whl"
```

## 简体中文

新增 Google Antigravity（`agy`）内置运行时支持、输入框区域解析以及 `sesskit>=0.3.2` 原生历史观测对齐。

### 变更内容

- **内置 `antigravity` 运行时（`agy`）**：将 `"antigravity"` 加入 `BUILTIN_RUNTIME_IDS`、`default_registry()` 与 `_resume_argv()`（`agy --dangerously-skip-permissions --conversation <id>`），并在真实 `agy 1.5.8` 终端界面验证了 `between_rules` 输入框解析与 `Escape` 中断键位。
- **未信任工作区弹窗识别**：扩展 `_BLOCKING_DIALOG_RE` 以识别 Antigravity 的 `↑/↓ Navigate · enter Confirm` 底部确认栏，避免在未授权确认弹窗上盲目粘贴输入。
- **MCP 边界声明**：实测 `agy 1.5.8` 在 `--settings` 中拒绝 `mcpServers`（返回 `unknown setting "mcpServers"`），因此明确声明不支持按会话注入 stdio MCP（`MCP_CHANNEL_UNSUPPORTED`），`agent-session-control acp --runtime antigravity` 在入口检查处明确拒绝执行，同时在文档中标注 `agy acp` 原生子命令。
- **SessKit 版本对齐**：将 `history` 可选依赖升级至 `sesskit>=0.3.2`（固定 `sesskit-0.3.2-py3-none-any.whl`），以消费 Antigravity 的类型化活动快照与增量读取（`typed_activity=True`、`incremental_reading=True`、`structured_questions=True`）。
- **端到端与实机一次性验证**：补充单元测试、控制器端到端测试（`plan` / `create` / `start_turn` / `HistoryObserver` 增量关联 / `load_history` / `resume`）、ACP 入口拒绝测试及一次性 `tmux` + `agy` 实机输入框探测测试，并同步更新文档与内置 `agent-session-control` skill。
