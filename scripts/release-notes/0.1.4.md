# 0.1.4

Fix superseded-turn settlement liveness, add atomic pre-dispatch cancellation and queued message withdrawal, and process queued control messages while awaiting contended target locks.

## Changes

- **Superseded-turn settlement (`SupervisorRunner.observation_changes`)**: When `observation["current_turn"]` is `False` (a later user message has started a new turn) and no own follow-up message remains unrecorded, the superseded turn settles immediately without waiting on the later turn's live phase, screen hash, or trailing assistant-message shape. Mixed-attribution superseded turns settle as `unknown` (`mixed_attribution`) and outcome-less superseded turns settle as `unknown` (`turn_superseded`) instead of deadlocking downstream target queues.
- **Target-lock wait message processing (`_wait_for_target`)**: While waiting behind a contended `target:` lock, pre-dispatch runs now evaluate `process_messages(None)` before sleeping so queued cancellations settle promptly.
- **Atomic pre-dispatch cancellation (`RunStore.cancel_queued` & `LocalController.interrupt`)**: Cancelling a `delivery="accepted"`, `execution="queued"` run atomically settles the run locally (`delivery="rejected"`, `execution="interrupted"`, `error.code="cancelled"`) and prevents `SupervisorRunner.dispatch()` from starting it concurrently; dispatched/running runs fall back to enqueuing a queued `interrupt`.
- **Control message withdrawal (`RunStore.withdraw_message`)**: Allows withdrawing a still-`queued` follow-up/control message (`state="withdrawn"`), which no longer blocks run settlement.
- **Tests & Contract**: Updated `docs/CONTRACT.md` and added regression tests in `tests/test_core_store.py` and `tests/test_engine_supervisor.py`.

## 简体中文

修复已被新回合接替（superseded）的运行无法结清导致阻塞队列的问题，新增未派发运行的同步取消与已排队控制消息撤回原语，并在等待目标锁期间处理控制消息。

### 变更内容

- **已被后续回合接替的运行结清（`SupervisorRunner.observation_changes`）**：当 `observation["current_turn"]` 为 `False`（会话历史中已有后续用户消息开启新回合）且本运行没有尚未落盘的自身追问/回答消息时，不再受后续新回合的活跃相位、屏幕刷新或尾部消息类型阻塞，立即按该回合自身结果结清；混合归因的超期回合结清为 `unknown`（`mixed_attribution`），无明确结果的被接替回合结清为 `unknown`（`turn_superseded`），防止整条目标队列永久饿死。
- **目标锁等待期消息处理（`_wait_for_target`）**：在等待被占用 `target:` 锁期间，未派发运行会在休眠前执行 `process_messages(None)`，使排队的取消请求能及时落盘生效。
- **未派发运行原子同步取消（`RunStore.cancel_queued` 与 `LocalController.interrupt`）**：对处于 `delivery="accepted"` 且 `execution="queued"` 的未派发运行，在存储事务内原子完成取消（`delivery="rejected"`、`execution="interrupted"`、`error.code="cancelled"`），同时防止 `SupervisorRunner.dispatch()` 并发下发；已开始派发或执行中的运行仍回退为排队 `interrupt`。
- **控制消息撤回（`RunStore.withdraw_message`）**：支持将尚未派发的 `state="queued"` 控制/追问消息撤回为 `state="withdrawn"`，且 `withdrawn` 状态不再阻塞运行结清。
- **契约与测试**：更新 `docs/CONTRACT.md`，并在 `tests/test_core_store.py` 与 `tests/test_engine_supervisor.py` 补充回归测试。
